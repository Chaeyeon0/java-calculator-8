# java-calculator-precourse

### 🚀 미션 개요

사용자가 입력한 문자열 안의 숫자를 모두 더하는 프로그램

문자열 안에는 쉼표(`,`)나 콜론(`:`)을 기본 구분자로 사용하며, `//[구분자]\n` 형식으로 커스텀 구분자를 지정할 수도 있다.

---

### 🗂️ 패키지 구조

```
src/main/java/
└── calculator
    ├── Application.java          // 프로그램 실행 및 입출력 담당
    └── domain
        ├── StringCalculator.java // 계산기 로직의 중심 (전체 흐름 조율)
        ├── ExpressionParser.java // 문자열 분석 및 구분자/숫자 분리 담당
        └── PositiveNumbers.java  // 숫자 변환, 유효성 검증, 합산

```

---

## 🧩 기능 요구사항

### 1️⃣ 기본 동작

- 사용자가 입력한 문자열을 분석하여 숫자를 모두 더한 결과를 반환한다.
- 예:
    ```
    입력: "1,2,3"
    결과: 6
    ```

### 2️⃣ 구분자 처리

- 기본 구분자: 쉼표(`,`), 콜론(`:`)
- 커스텀 구분자:
    - 문자열이 `"//"`로 시작하고, `\n` 전까지의 문자를 구분자로 사용한다.
    - 예:
        ```
        입력: "//;\n1;2;3"
        결과: 6
        ```
        
- 기능 목록:
    - [ ]  기본 구분자(`,`, `:`) 이외의 커스텀 구분자가 있는지 확인
    - [ ]  있다면 커스텀 구분자를 추출
    - [ ]  구분자를 제외한 숫자 문자열 추출
    - [ ]  문자열을 구분자로 split 처리


### 3️⃣ 유효성 검사

- 입력값이 비어 있으면 0을 반환한다.
- 구분자나 숫자에 잘못된 문자가 포함되면 예외를 발생시킨다.
- 음수 입력 시 예외를 발생시킨다.
- 기능 목록:
    - [ ]  구분자가 숫자인지 확인
    - [ ]  문자로 된 숫자가 실제 정수인지 확인
    - [ ]  숫자가 아닌 문자가 있는 경우 예외 발생
    - [ ]  음수인 경우 예외 발생


### 4️⃣ 계산 기능

- [ ]  문자열을 입력받는다.
- [ ]  구분자로 나누어진 숫자들을 추출한다.
- [ ]  검증을 통과한 숫자들을 모두 더한다.
- [ ]  결과를 출력한다.

---

### 구현 흐름

1. `Application`에서 문자열 입력을 받는다.
2. `StringCalculator`가 전체 흐름을 제어한다.
3. `ExpressionParser`가 문자열을 분석해 구분자와 숫자 리스트를 만든다.
4. `PositiveNumbers`가 숫자 유효성을 검증하고 합계를 계산한다.
5. 최종 결과를 콘솔에 출력한다.
